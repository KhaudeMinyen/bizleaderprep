PROJECT OVERVIEW
================================================================================
BizLeaderPrep is an FBLA Middle School competition prep application built with
React 19, TypeScript, and Vite. It features a study dashboard, competitive event
exploration, daily quizzes, leaderboard ranking, and Supabase authentication.

Stack:
  - Frontend: React 19 + TypeScript + Vite
  - Backend: Supabase (PostgreSQL, Auth, Realtime)
  - Hosting: Vercel (SPA with rewrites)
  - Styling: Tailwind CSS + inline styles
  - Data: FBLA MS Questions table, user_favorites table


KEY FEATURES & ARCHITECTURE
================================================================================

1. AUTHENTICATION & SESSION MANAGEMENT
   - Supabase OAuth (Google) with detectSessionInUrl: true
   - Custom session detection for OAuth hash (#access_token=...)
   - onAuthStateChange listeners for SIGNED_IN, INITIAL_SESSION, SIGNED_OUT
   - Automatic redirect to portfolio on OAuth completion
   - Session persists via localStorage + Supabase

2. CLIENT-SIDE ROUTING (No React Router)
   - ViewState union: 'landing' | 'portfolio' | 'study' | 'auth' | 'events'
   - window.history.pushState/replaceState for URL management
   - popstate listener syncs URL changes back to state
   - Routes:
     - / → landing (Hero page)
     - /dashboard → portfolio (main dashboard)
     - /dashboard/events → events (all 17 events explorer)
   - Vercel SPA rewrites ensure all routes serve index.html

3. DAILY QUESTION SYSTEM
   - One question per day per user (localStorage-based)
   - LocalStorage keys: prephub_daily_question_YYYY-MM-DD, prephub_daily_answered_YYYY-MM-DD
   - Deterministic seed from date ensures same question for all users same day
   - Seed calculation: parseInt(todayKey.replace(/-/g, ''), 10)
   - Once answered, box grays out (opacity: 0.45, pointerEvents: none)
   - Answer stored when user clicks option
   - Next question appears automatically the following day
   - Displayed as "Daily Question" in dashboard left panel

4. FAVORITES / SAVED EVENTS
   - Stored in Supabase user_favorites table (event_name, user_id)
   - Also synced to localStorage (prephub_favorites)
   - Populated on login via useEffect + supabase.from('user_favorites').select()
   - Star icon toggles favorite status; shows "SAVED" badge when favorited
   - Only available to logged-in users
   - Used to filter daily question event selection if favorites exist

5. STATS & MASTERY TRACKING
   - Questions Answered: tracked via localStorage (prephub_usage)
   - Accuracy Rate: calculated from masteryScores JSON (prephub_mastery)
   - Events Studied: count of keys in masteryScores
   - Saved Events: length of favorites array
   - All stats populated on dashboard stats grid (4 cards)

6. EVENTS PAGE (/dashboard/events)
   - Two-column layout:
     - Left (300px): All 17 MS competitive events list with star favorites
     - Right (flex): Event details (type, description, knowledge areas, NACE)
   - First event selected on page load
   - Hover/click event on left to view details on right
   - "Study this event" button navigates to StudyView
   - Stars sync with Supabase favorites; prompt login if not authenticated
   - Event info sourced from MS_EVENTS_INFO_DATA object (embedded in App.tsx)

7. DASHBOARD (PORTFOLIO VIEW)
   - Stats grid (4 columns): Questions, Accuracy, Events Studied, Saved Events
   - Saved Events panel: shows up to 6 favorited events with scores
   - Daily Question panel: one question per day, grayed out after answered
   - Leaderboard panel: top 5 this week (hardcoded mock data)
   - Apex card: study companion chat bot (mock implementation)
   - All sections animate in via dsFadeUp keyframes

TROUBLESHOOTING & DEBUGGING
================================================================================

Blank Dashboard on OAuth Login:
  - Symptom: After Google sign-in, blank black screen
  - Cause: OAuth hash (#access_token=...) not parsed before session check
  - Fix: Check isOAuthRedirect flag, wait for onAuthStateChange SIGNED_IN
  - Verify: Supabase redirectTo URL matches whitelisted URL in OAuth project

Session Not Persisting:
  - Check: localStorage for prephub_favorites, prephub_usage
  - Check: Supabase session cookie in DevTools
  - Verify: User_favorites table has correct user_id FK

Daily Question Not Updating:
  - Symptom: Same question showing multiple days
  - Cause: localStorage prephub_daily_question_YYYY-MM-DD persists
  - Fix: Manual localStorage clear or wait until date changes
  - Verify: Today's date key changes at midnight local time

Canvas Grid Not Visible:
  - Check: Hero.tsx useEffect + rAF loop firing
  - Check: Canvas z-index is 1, content is z-index 2 or higher
  - Check: BASE_ALPHA not 0, MAX_ALPHA not 0
  - Verify: Mouse movement triggers glow (check console for mouse events)

Events Page Not Loading:
  - Check: View state is 'events'
  - Check: /dashboard/events URL is set via pushState
  - Verify: MS_EVENTS_INFO_DATA fully populated (all 17 events)
  - Check: hoveredEvent initialized to MS_EVENTS_LIST[0]
